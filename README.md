# ClashFlow 安装包

本仓库用于分发 ClashFlow 的 macOS 安装包。源码仓库保持原有位置，本仓库不上传应用源码。

请前往 [Releases](https://github.com/apiao671/ClashFlowApp/releases) 下载附件，并按发行说明选择版本和架构。

- 需要 macOS 13 或更新版本。
- `.dmg` 用于手动安装，`.app.zip` 为应用内更新格式；SHA-256 校验文件随发行提供。
- 安装包默认发布为预览版，架构以附件文件名为准。
- 当前 Alpha 3 客户端的更新源仍指向 Gitee；本仓库上传安装包不会自动切换已安装客户端的更新地址。
- 当前安装包使用本地签名，尚未经过 Apple 公证。
